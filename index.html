What we believe

A small set of rules we don't break, no matter how many games we ship.

Rule one

Original first

Every game starts from a mechanic we haven't seen before, not a genre we're chasing. If it feels like something else, we haven't found the game yet.

02

Premium, built by hand

Every visual and sound is procedural — generated in code, not pulled from an asset store.

03

No dark patterns

"One more run" should feel like your own idea. We never guilt, pressure, or trick.

04

Accessible by default

Colorblind-safe, readable, and playable by as many people as the game allows.
